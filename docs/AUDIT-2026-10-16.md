# Разбор аудита 0.35.0 → исправления 0.35.2

Аудит сверен с `main` версии 0.35.1 (`87ddff8`). Он правильно описывает
несколько пробелов, но не запускал тесты и оценивал часть покрытия по прямым
импортам. До исправлений реально проходили 124 теста, после — 144 основных
теста и 14 тестов Google Docs. Прямое отсутствие импорта модуля в тесте не
означает отсутствие покрытия: проверки архивов запускают настоящий worker.

## Проверка

- `npm test`: 144/144, без пропусков; сборка выполняется через pretest.
- `npm run check`: версии, локальные ресурсы, CSP, синтаксис, состав обоих ZIP,
  first-party API policy и 12 vendor/font/license assets проходят.
- Google Docs: 14/14 тестов; ZIP собран.
- Writer: Python compile и OXT-сборка проходят. Native LibreOffice/UNO отсутствует
  локально; окончательный результат проверяется workflow CTT Writer в PR.
- PDF.js и SheetJS: независимая сборка с точным совпадением байтов.
- `npm audit --audit-level=high`: 0 известных замечаний для npm lockfile на момент
  проверки. Это не проверяет отдельно встроенные runtime-бандлы.

Изменения не означают автоматически ни выкладку сайта, ни отправку в CWS/AMO.
Открытые пункты не скрываются зелёным CI: выбор лицензии, включение приватного
канала GitHub, проверка HTTP-заголовков хостинга, воспроизводимость шрифтов,
долгосрочная поддержка vendor-зависимостей и более широкое fuzz/performance-тестирование.
