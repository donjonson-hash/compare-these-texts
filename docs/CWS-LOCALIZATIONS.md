# Локализация названия и краткого описания CTT

Подготовлено для Chrome Web Store, версия 0.35.4. Все 19 запрошенных языков: 21 локализованный вариант с учетом регионов и английский резервный — 22 локали.

## Подход

Бренд Compare These Texts сохраняется. После него — естественная местная формулировка сравнения и правки текста. Формулировки отредактированы с учетом языка; названия на французском, испанском, итальянском, португальском, русском и вьетнамском уточнены по результатам проверки ключевых запросов в Semrush от 16 октября 2026 года. Рост позиций или установок не гарантируется.

Интерфейс редактора, справка и юридические страницы остаются английскими. Каждое неанглийское краткое описание прямо сообщает об этом. Никаких заявлений о переводе документов или использовании внешнего ИИ нет.

## Упаковка и публикация

Канонические тексты: `extension-package/store/localizations.json`. Сборка Chrome создает `_locales/<locale>/messages.json`; `manifest.json` использует `__MSG_extensionName__`, `__MSG_extensionDescription__`, `__MSG_actionTitle__` и `default_locale: en`. Английские название, описание и подсказка сохранены. Firefox в этой задаче сохраняет английские метаданные: локализация карточки AMO не выполнялась.

Для Chrome используются официальные коды `no` (норвежский), `fil` (филиппинский), `pt_BR`, `pt_PT`, `es`, `es_419`. Варианты немецкого для Германии, Австрии и Швейцарии покрывает `de`; отдельные одинаковые каталоги не нужны.

1. После слияния собрать ZIP Chrome и загрузить его как новую версию существующего CTT в Developer Dashboard.
2. Название и краткое описание берутся из локализованного manifest. Проверить их отображение после загрузки.
3. В Store listing выбрать каждую локаль и вставить соответствующий готовый текст из [полных описаний](../extension-package/store/descriptions/README.md). Полные описания не подставляются из manifest или messages.json. Скриншоты и видео локализуются отдельно в кабинете.
4. Сохранить английский язык интерфейса явно указанным; отправить обновление на проверку. Создавать отдельное расширение для каждого языка не требуется.

Публикация в Chrome Web Store не выполняется автоматически при слиянии PR. Сайт этим PR не переводится.

## Проверки

`npm run build && npm run check` проверяет список локалей, длины строк, отсутствие управляющих символов и подстановок, английский резервный вариант, содержимое каждого messages.json и полноту ZIP. Сторонние лицензии, CSP, разрешения и файлы редактора остаются под существующими проверками.
