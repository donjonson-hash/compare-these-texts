# Welcome page Compare Two Texts

Подготовлено 26 октября 2026 как отдельное изменение для следующего обновления. Текущая модерация Chrome Web Store не меняется. Номер версии не повышен; тестовый пакет не предназначен для загрузки в магазин.

## Основания

- В видимой истории пользователь выбрал название Compare Two Texts, простой первый экран и минимум вводного текста. Данные о большей стабильности запроса были сообщены пользователем; в этой задаче они заново не проверялись.
- Приложенный Compare_These_Texts.docx содержит исторические ключи Semrush US от 4 октября 2026 и описание прототипа 0.33.6. Старые бренд, домен и способ ручной установки не перенесены в новую страницу.
- extension-package/store/KEYWORDS.md сохраняет те же ключи. Это Google volume, не статистика Chrome Web Store. Новое исследование частотности не проводилось.
- extension-package/store/BOOTCAMP-CHECKLIST-RU.md фиксирует welcome внутри ZIP, повторный вход Getting started, английский интерфейс и честное описание ограничений. Ориентир 4500 символов и 10–16 блоков относится к описанию карточки, а не welcome. Полный исходный материал курса не найден; этот чек-лист не объявляется полным изложением курса.
- Поиск истории через Personal Context оказался недоступен. Выводы основаны на доступной истории и перечисленных документах.

## Что изменено

Первый экран сообщает конкретное действие: Compare two texts. Edit the differences. Главная кнопка Try an example использует существующий безопасный запуск примера, дополнительная Compare my files открывает рабочее окно без подмены черновика. Четыре коротких шага повторяют сценарий Upload → See → Edit → Download.

Небольшой пример A/B явно подписан Example и является иллюстрацией различий, а не снимком интерфейса. Справка раскрывается по запросу: форматы, один документ, закрепление расширения, хранение. Локальность и основные ограничения видны сразу. Сохранены ссылки на privacy, support, terms; внешних скриптов и новых разрешений нет.

## Проверка и выпуск

Существующие проверки first-install, запуска примера и защиты черновика обязательны. Перед публикацией следующего обновления повысить номер версии согласованно, пересобрать финальный пакет и обновить магазинный скриншот welcome. Пока можно проверить через Load unpacked в отдельном профиле, чтобы не смешивать рабочие черновики и тестовые данные.

## Выполненная проверка

Сборка, статические проверки и 4 существующих теста welcome прошли. В браузере проверены первый экран, раскрытие справки, переход Compare my files к рабочему окну и ширина 390 px. Иллюстрация подписана Example; логотип использует тот же favicon.svg CTT, что и рабочее окно. В подсказке для одного документа указана фактическая верхняя кнопка Edit & convert. Полный запуск сравнения внутри установленного тестового расширения в этой проверке не выполнялся; HTTP-предпросмотр не заменяет проверку extension origin и Web Crypto.

## Ревью 30 октября 2026

В CI обнаружено, что блок справки вытеснял нижнюю часть страницы за границы магазинного скриншота 1280×800. Справка собрана под одним раскрываемым заголовком; все вопросы и ответы сохранены. Проверка размера скриншота остаётся обязательной.
