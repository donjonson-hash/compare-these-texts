documented redirect/header settings. Native tools manage domain registration
and validation, not these HTTP rules. The existing `_headers` file declares HSTS,
but the checked response lacks it. Do not claim HSTS is enabled from source alone.

Request supported server-side configuration from the hosting provider:

> Please configure permanent 301 or 308 redirects from HTTP to HTTPS for

## "Compare two lists" product-fit check — 30 October 2026

Decision: no list guide now; revisit after Show HN using Search Console queries.

Search data (Semrush US): "compare two lists", "compare lists" and "list compare"
share one 22,200 cluster with navigational intent (many searchers want
comparetwolists.com). Reachable queries: list comparison tool (1000 / 21),
compare two lists online (170 / 32), compare lists online (140 / 33), compare two
lists excel (110 / 13). The top 10 are dedicated list tools that treat lists as
sets: paste two lists, ignore order, show only-in-A / only-in-B / in-both with
counts, ignore case, trim, tolerate duplicates, copy each group. At least one
leader (ipvoid) also processes locally, so privacy is not a differentiator here.

Product today (checked in code and the built site):

- Pasted text uses the document text engine: correct unique items on clean data,
  but common items are split into Matched and Moved; with real-world noise it
  reports false changes (two shared items paired as a change), treats case and
  trailing spaces as differences and is thrown off by duplicates.
- Single-column CSV via the table engine gives correct set results only after a
  header row, upload, choosing the key on both sides, "Check only whether items
  are present" and "Ignore leading and trailing spaces"; case is not ignored and
  the first duplicate stops the comparison ("Resolve the duplicate key").
  That strictness is intentional for SKU matching.

Minimum to compete: a separate list mode (not the table engine) with pasted
input split by lines or commas, order-independent comparison, trim by default,
an ignore-case option, duplicates counted rather than rejected, and three
copyable groups with counts; plus one guide targeting "list comparison tool".
Estimate 1–2 days with tests. It extends beyond document comparison, whose
users are the extension's core audience.
