## Как считались употребления

Подсчёт относится только к текущему `descriptions/en.txt`, включая заголовки,
без названия карточки, краткого описания и этой таблицы. Регистр игнорируется,
последовательности пробелов и переносов нормализуются, учитываются границы слов.
Вложенные фразы считаются отдельно. Колонки Times used из старого документа
пересчитаны для текущего, более короткого текста; они не скопированы из старой
редакции.

Ноль означает, что фраза оставлена в резерве. Не вставляйте список синонимов
в описание и не повторяйте ключи ради квоты. Старый ориентир около 4 500 символов
не требует удлинять согласованный текст, сейчас он содержит 2 402 символа
без завершающего переноса строки.
