Compare Two Texts — сравнение текстов и документов рядом, поиск отличий и редактирование результата. Проверьте новую версию документа, сверьте таблицу поставщика или заполните строку для ручного ввода в поддерживаемом PDF. Затем скачайте или распечатайте результат.

СРАВНИТЕ, ИСПРАВЬТЕ, СОХРАНИТЕ
1. Откройте расширение и выберите два файла для сравнения либо используйте Edit & export для одного файла.
2. Просмотрите подсвеченные отличия и внесите изменения.
3. Скачайте результат или отправьте его на печать с помощью доступных для этого формата функций.

ЧТО МОЖНО СДЕЛАТЬ
- Сравнивать тексты TXT и Word DOCX, PDF с выделяемым текстом и таблицы CSV/TSV или Excel XLSX.
- Видеть две версии рядом, переходить между отличиями и редактировать текст в окне сравнения.
- Для таблиц — выбирать лист, сопоставлять строки по идентификатору и указывать столбцы для проверки. Изменять значения ячеек и копировать отсутствующую строку из A в B.
- Проверять изменённые денежные суммы и проценты при сравнении текстов, Word и поддерживаемых PDF с помощью Amounts & percentages.
- Работать с одним документом в Edit & export. В поддерживаемых PDF с текстовым слоем можно нажать на обнаруженную строку для ручного заполнения и ввести данные либо разместить надпись с помощью Add text. Размер текста подстраивается под доступное место; Format позволяет настроить его вручную.
- Экспортировать поддерживаемые документы Word DOCX в PDF с предпросмотром перед скачиванием. Поддерживаемые колонтитулы, номера страниц и простые горизонтальные линии включаются в результат; разбиение на страницы и шрифты могут отличаться от Word.

ЛОКАЛЬНАЯ ОБРАБОТКА
Документы обрабатываются на вашем устройстве. Расширение работает без интернета и не загружает документы на сервер для сравнения или редактирования. Черновики сайта и расширения хранятся отдельно, без автоматической синхронизации. Скачайте копию готовой работы.

ПЕРЕД НАЧАЛОМ РАБОТЫ
- Интерфейс редактора пока на английском языке. Переведённые описания в магазине не меняют язык редактора.
- Размер каждого входного файла — до 2 MiB.
- PDF должен содержать текстовый слой: сканы без текста не поддерживаются, распознавания OCR нет. Печатные строки для ручного заполнения отличаются от интерактивных полей PDF-форм. Интерактивные поля и комментарии PDF не поддерживаются.
- Изображения и оформление не сравниваются. Сохранение исходного оформления PDF зависит от документа; для сложной вёрстки может потребоваться экспорт только текста. Вёрстка Word может отличаться от отображения в Microsoft Word.
- Перед импортом DOCX перенесите сноски, концевые сноски и комментарии в основные абзацы копии документа.
- Для сравнения двух файлов таблиц необходима одна строка заголовков, без объединённых ячеек, со значениями вместо формул.

Начните со встроенного примера документа или CSV / Excel, чтобы попробовать работу расширения перед открытием собственных файлов.
