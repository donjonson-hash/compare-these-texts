Compare Two Texts hjälper dig att granska två versioner av ett dokument och se vad som har ändrats. Versionerna visas sida vid sida, med tillagd, borttagen och ändrad text markerad. Använd tillägget när du kontrollerar ett reviderat avtal eller granskar ändringar i ett utkast.

Öppna två filer som stöds eller klistra in din text i arbetsytan. Granska skillnaderna, gör korrigeringar och spara resultatet med de tillgängliga exportalternativen. Med ett inbyggt exempel kan du prova arbetsflödet innan du öppnar dina egna dokument.

Jämförelse och redigering sker på din enhet. Dina dokument laddas inte upp till någon server för dessa åtgärder, och tillägget kan användas utan internetanslutning.

Jämförelsen gäller text, inte sidlayout eller bilder. PDF-dokument måste innehålla markerbar text; skannade sidor stöds inte. Varje indatafil får vara högst 2 MiB. Formateringen vid export kan skilja sig från originalet.
