# Compare Two Texts — локализация кандидата 0.37.9

Подготовлено 8 ноября 2026. Для кандидата определены 51 локали интерфейса и подготовлены 51 локали карточки магазина. Готовность интерфейсных каталогов к выпуску проверяется строгой сборкой. Публикация в Chrome Web Store выполняется отдельно; этот документ не утверждает одобрение магазина или успешное прохождение CI и браузерных проверок.


Переводы включают тексты карточек, подготовленные ИИ, и машинный перевод строк интерфейса с выборочной проверкой ИИ. Внешний перевод разрешён владельцем для проектных подписей, сообщений и справки на этапе подготовки; пользовательские документы не отправляются и не переводятся. Проверка структуры и полноты не гарантирует естественность перевода.

## Редакционная проверка

Лимиты метаданных: 75 UTF-16 единиц для имени и 132 для краткого описания. Английское название и краткое описание сохранены. Для новых языков подготовлены переводы, а не копии английского шаблона. В существующих переводах исправлены устаревшие утверждения English-only и добавлены сведения о черновиках и пилотах Office. Полноту каталогов интерфейса проверяет обычная сборка. Браузерные и установочные проверки должны оценить фактическое поведение и отображение; их результаты публикуются отдельно.

Переводы **не прошли проверку носителями всех 51 локалей**. Проверка полноты файлов, длины, кодов и технических ограничений не заменяет языковую редактуру. Существующие переводы сохранены по возможности; новые требуют проверки естественности терминов перед широким продвижением соответствующей локали.

Ориентир буткемпа «около 4 500 символов и 10–16 блоков» не считается обязательным правилом Google. Описания не удлинялись повторением ключей. Частотность Google не выдаётся за частотность Chrome Web Store; нет обещаний роста установок. Исторические значения Semrush не называются новым исследованием.

## Функции и ограничения в текстах

- TXT, DOCX, PDF с текстовым слоем, CSV/TSV, XLSX; сравнение, правка и доступный для формата экспорт.
- PDF: заполнение поддерживаемых печатных пустых мест и добавление текста. Не заявляются OCR, сканы без текста, интерактивные PDF-формы и комментарии.
- DOCX → PDF: предварительный просмотр, поддерживаемые колонтитулы и номера страниц. Нет гарантии точного воспроизведения сложного макета Microsoft Word.
- Изображения и форматирование не сравниваются; сложный макет может экспортироваться только как текст. Сноски, концевые сноски и комментарии DOCX не импортируются.
- Для сравнения двух таблиц нужны один ряд заголовков, отсутствие объединённых ячеек и значения вместо формул.
- До 2 MiB на каждый входной файл.
- PDF-отчёты могут использовать английские подписи, если встроенный шрифт или обработка письма не поддерживает выбранный язык; пояснение показывается перед экспортом. Авторитетный текст программной лицензии остаётся английским.
- Основной сценарий расширения работает локально и офлайн, без загрузки документов для сравнения и правки. Черновики AES-GCM-256 с ключом в браузерном профиле не являются хранилищем с паролем; скачанные файлы не зашифрованы. Черновики истекают после семи дней без использования. Хранилища сайта и расширения раздельные.
- Пилоты Word и Google Docs устанавливаются отдельно и имеют свои условия конфиденциальности. Заявление об офлайн-обработке расширения не переносится на эти интеграции.

## Перед отправкой в магазин

1. Сопоставить карточку с фактической сборкой: полные каталоги 51 локалей, переключение языка без потери правок, RTL и офлайн-работа. Проверки метаданных не заменяют проверки интерфейса.
2. Проверить все 51 названия, коротких и полных описания, переносы и RTL-предпросмотр для арабского, персидского и иврита.
3. Проверить соответствие скриншотов опубликованному интерфейсу. Локализованные скриншоты не заявлять без подготовки.
4. Отдельно сверить инструкции модератору, политику конфиденциальности, release notes и контрольные суммы финального комплекта.
5. В кабинете владельца проверить ID карточки, страны распространения, контактные сведения и поля Data usage по актуальной форме. Подготовка файлов или PR сама по себе не отправляет заявку.
