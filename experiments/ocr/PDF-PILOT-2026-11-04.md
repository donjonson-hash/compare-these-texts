# PDF page review pilot — 2026-11-04

The isolated browser pilot now accepts scanned and mixed PDFs alongside images.
Production source, manifests and the released extension version remain unchanged.

## Behavior

- PDF up to 20 MiB / 30 pages; one rendered page at a time, at most 4 million pixels and 4000 pixels per dimension.
- Existing text layers are extracted first; scanned pages can be recognized locally with the bundled Tesseract EN/RU models.
- Text and approval are kept per page. Editing or changing recognition settings invalidates only that page.
- Comparison and full-document TXT export require all pages to be confirmed.
- Explicit no-text confirmation is required for empty pages.
- Difference links reopen the relevant page. Comparison is by page and line position, not semantic page alignment.
- Password-protected, malformed, over-limit or unsupported-resource PDFs fail visibly.
- PDF annotations and form fields are excluded; this limitation is shown in the PDF interface.
- Replacement and cancellation invalidate pending asynchronous OCR/rendering output.

## Validation

7 PDF boundary/text-preservation unit tests and the existing 26 Python tests passed.
Real Chromium 153.0.8010.0 checks passed on the working source and on the extracted
portable ZIP: mixed text/scan routing, real OCR, page approval persistence, exact
TXT download with page markers, edit invalidation, difference navigation, explicit
blank review, invalid PDFs and cancellation followed by replacement. The existing
image-only browser regression also passed. Observed external requests and page
errors: zero. Network isolation is enforced by the test harness; no production
extension CSP claim is made.

Synthetic PDFs were independently checked with pypdf; sample pages were rendered
with Poppler and visually reviewed. Fixture generation is repeatable across output
directories. Browser screenshot inspection found no overlapping controls. The
inline preview is an overview; use the full-size image link for proofreading.

This is not a real-world accuracy benchmark or a Firefox validation. Text layer
order may differ from reading order, and OCR may produce false differences.
All documents and approvals remain in memory only; refresh discards them.
