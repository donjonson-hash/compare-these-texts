# OCR pilot results — 2026-11-04

## Decision

OCR is useful for image-only document comparison, but neither candidate is ready
for automatic integration into Compare Two Texts. Keep this experiment isolated.
The portable pilot uses browser-local Tesseract with an explicit review gate.
Xiaomi remains an optional external-engine candidate, requiring a separate local
inference process and model installation. It is not bundled in the browser pilot.

## Scope and method

24 synthetic PNG pages (1200×1600): English/Russian, six categories, A/B pairs.
The same image and reference hashes were used for both engines. These are not
customer documents, a representative real-world corpus, or a proof of market demand.
Ten pairs have a known change; two degraded pairs have identical source text.

The main metric is micro-averaged character edit rate (CER), after NFC and
whitespace normalization. Case, punctuation and literal numeric tokens remain
significant. Exact pages means exact normalized transcription, not visual fidelity.
A secondary table-format diagnostic removes only validated Markdown table syntax;
it was added after observing Xiaomi output and is explicitly exploratory.

Tesseract.js 7.0.0 ran in Chromium 153.0.8010.0 with pinned English/Russian language
assets, OEM 1. PSM 6 is the baseline. PSM 3 is a targeted configuration comparison,
not a replacement selected solely on its overall score.
Xiaomi used the BF16 community package referenced by its official repository,
llama.cpp b12091, four CPU threads, context 16384, temperature 0, seed 0,
non-thinking mode, and the prompt `Extract the text in the image.` on whole pages.
This does not reproduce Xiaomi's published two-stage document pipeline.

The machine is a shared cloud Xeon 8573C, Linux x64, cgroup CPU quota 8 CPUs,
memory limit 8 GiB. Timings are measured sequential per-page recognition calls,
excluding model download and browser worker initialization. They are not laptop
performance promises or controlled single-tenant speed benchmarks.

## Measurements

| Engine / settings | Successful pages | Exact pages (successful) | Raw CER | Numeric recall | Median recognition time (successful) |
| --- | ---: | ---: | ---: | ---: | ---: |
| Tesseract PSM 6 | 24/24 | 4/24 | 6.59% | 87.30% | 1.50 s |
| Tesseract PSM 3 | 24/24 | 4/24 | 6.50% | 87.30% | 0.87 s |
| Xiaomi BF16 CPU | 23/24 | 10/23 | 8.31% | 96.73% | 59.05 s |

Xiaomi non-successful pages: `rus-small_font-b` (timeout).
The adapter request deadline was 180 seconds per page. Failed pages are visible
but excluded from error rates and successful-call median times. A timeout is an
operational failure of this tested configuration; the cause of any slowdown was
not isolated. It is not evidence of a universal model latency limit.

The aggregate CER values have different successful-page denominators when a run
fails. The matched-success comparison below uses exactly the same page ids, and
still measures only this small synthetic dataset:

- **Tesseract PSM 6, matched subset** (23 pages): raw CER 6.93%; after secondary table-format normalization CER 6.93%, exact pages 4/23.
- **Xiaomi, same successful subset** (23 pages): raw CER 8.31%; after secondary table-format normalization CER 2.41%, exact pages 16/23.

Raw Xiaomi scores can be inflated by Markdown table separators even when cell
text is correct. The secondary metric must not be presented as raw OCR accuracy
or used to erase genuine case, punctuation, number or reading-order changes.

## Findings that affect product behavior

- Tesseract PSM 6 interleaved English and Russian two-column text. PSM 3 fixed the
  tested English columns but damaged invoice order; Russian columns remained
  problematic. Keep automatic layout as an explicitly experimental option.
- Xiaomi preserved column order in the tested samples, but changed Russian
  heading case and confused some `O0` / `I1` identifiers. Its plain-text prompt
  also emitted Markdown tables. Do not silently accept model output as source text.
- Literal numeric recall does not prove that a value stayed attached to the
  correct label or cell. More exact changed-value tests are needed before shipping.
- Tesseract PSM 6: 1/2 completed unchanged pairs produced a false difference; 0/10 completed changed pairs missed **any** change; 0 pairs incomplete. This does not measure localization or detection of every individual edit.
- Xiaomi: 1/2 completed unchanged pairs produced a false difference; 0/9 completed changed pairs missed **any** change; 1 pairs incomplete. This does not measure localization or detection of every individual edit.

## Verification and resource limits

26 Python tests passed. Browser UI checks passed for upload, OCR, explicit
confirmation, comparison, edit/settings invalidation, malformed replacement,
cancellation and replacement. The portable v2 ZIP was extracted and exercised;
all 93 included file checksums were verified, and its UI matches this source.
The browser test observed zero external requests while actively blocking them.
The standalone development UI itself does not enforce a production network CSP.

The two repeated degraded-page samples produced identical text on consecutive
Tesseract calls. This limited check is not a cross-device determinism guarantee.
Xiaomi was not rerun for repeatability or tuned after failures in this run.

Browser memory observations cover only sampled main-thread JS heap, not workers
or WASM. Xiaomi server peak RSS and runtime details are in [xiaomi-probe.md](xiaomi-probe.md).
These measurements are not comparable total-memory benchmarks. The model plus
projector occupy 1,765,009,376 bytes on disk and are excluded from the pilot ZIP.
