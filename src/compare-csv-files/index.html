FILE COMPARISON GUIDE

Compare two CSV files

A CSV diff that finds changed fields and missing records in two exports, even when rows are in a different order.

Open document comparisonAdd to Chrome — free

Prepare the exports

Use UTF-8 CSV or TSV files up to 2 MB each, with no more than 5,000 data rows per file. Keep one header row with clear column names. Choose a stable identifier, such as SKU or record ID, that appears in both exports.

Check that identifiers are present and unique. Preserve leading zeros in codes such as 00125. An order number and a product code are different keys; choose the one that identifies a complete record in your files.

How to compare two CSV files

  1. Load both files. Upload the earlier export under A and the later export under B, then choose Compare documents.
  2. Check the delimiter. Start with automatic detection. If the columns are interpreted incorrectly, choose comma, semicolon or tab in the comparison settings.
  3. Confirm the mapping. Select corresponding identifier columns and the value fields to check. Review this mapping when the exports use different header names.
  4. Inspect and save. Review changed values and items present only in A or B. Use the spreadsheet controls to edit supported values or download the comparison report.

Example: a supplier export

Illustrative comma-delimited records:

A:
sku,quantity,price
LAMP-01,12,35.00

B:
sku,quantity,price
LAMP-01,10,35.00

Choose sku as the identifier and check quantity and price. The quantity changes from 12 to 10; the price stays the same.

Read the result in context

A record found on one side is not automatically an error: it may be a new or removed item. If no identifiers match, check the selected columns and the exported codes before drawing conclusions. Units and currencies are not converted.

CSV has no workbook styling or formulas to preserve. Document contents are processed in your browser; see Your files & privacy.

Common questions

Why does the file appear as one column?

The delimiter may be wrong. Check whether the export uses commas, semicolons or tabs and select the matching option.

Why do accented characters look wrong?

Export the original data again using UTF-8 encoding. Renaming a file does not change its encoding.

Can I use XLSX instead?

Yes. See how to compare Excel files for sheet selection and values-only requirements.
