GET THE EXTENSION

Your document workspace, offline.

Open Compare Two Texts from your browser toolbar. Compare, edit and export files on your device.

Available in the Chrome Web Store

01

Chrome & Edge

Install from the Chrome Web Store and keep the workspace one click away.

Get the Chrome extension
  1. Open the store page and select Add to Chrome. In Edge, allow extensions from other stores if prompted.
  2. Confirm installation, then pin Compare Two Texts to your browser toolbar.
  3. Open the extension and choose Try an example or load your own documents.

Already using the unpacked preview? Download any documents you want to keep before switching. Saved drafts do not transfer automatically to the store installation.

02

Firefox

Try a temporary installation for the current browser session.

Download for Firefox
  1. Download and extract the ZIP.
  2. Open about:debugging#/runtime/this-firefox.
  3. Select Load Temporary Add-on and choose manifest.json in the extracted folder.
  4. Click the Compare Two Texts toolbar icon to open the workspace.

Requires Firefox 142 or later. Load the temporary add-on again after restarting Firefox. Download your results before ending the session.

What you can do

Compare DOCX, text-based PDF, TXT, XLSX, CSV and TSV files, up to 2 MB each. Jump to differences, edit supported text or table cells, and download the result. Open Edit & convert for a single document, including DOCX-to-PDF conversion and PDF editing.

In Word, PDF and text comparisons, All tools groups review and editing tools, file settings and reports. The Help page shows where to find each action and explains format limitations.

Offline processing, separate saved work

The extension processes documents locally without an external AI service. Saved drafts are encrypted with AES-GCM-256 on this device, with no account or password required. Once installed, document processing works offline. Opening this website or a support link still requires an internet connection.

The two website addresses and each installed extension keep separate drafts with no automatic sync. Download a document to move it between workspaces. Saved work expires after 7 days without opening or saving it; it is not a permanent backup. Read Your files & privacy for details.

Prefer to use the website?

No installation is needed to compare or edit in your browser.
