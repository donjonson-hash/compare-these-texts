Compare files: choose your guide

Each guide explains how to prepare a file, review differences and avoid common format problems.

  • Compare Word documents — DOCX text, paragraphs and tables.
  • Compare PDF files — selectable text, edits and export limits.
  • Compare Excel files — sheets, identifiers and values-only copies.
  • Compare CSV files — delimiters, row matching and checked columns.

These guides open on the website; the comparison engine also works in the offline extension.

Edit inside Word or Google Docs

Open Word & Google Docs add-ins for the separate selected-text editor prototypes, installation instructions and the Google Docs package. They edit a selected passage inside the host program after preview. Installation is manual; the browser extension does not install either add-in automatically.

These add-ins require an internet connection and have their own data handling. Google Apps Script processes text in Google’s infrastructure and temporarily caches the selected paragraph in plaintext. Read the installation hub before choosing this mode.

Compare two documents

Paste text into A and B, or choose Upload file for each side, then select Compare. Use Next difference to jump between changes. In a Word, PDF or text comparison, select a passage to edit it, or start a review to choose Use A or Keep B.

Select Home or the CTT logo to return to the start screen. Your open work remains available through Continue previous comparison or Continue editing.

Where are the extra tools?

In a Word, PDF or text comparison, select All tools above the documents:

  • Review & edit — find and replace, zoom, review decisions, amounts and percentages, copy and restore.
  • Files & settings — change source documents, switch work mode and manage saved work.
  • Reports — download a comparison report or open Explain changes.

Reports and Explain changes describe the original comparison. Download edited documents using the controls for A or B. Spreadsheet views have their own sheet, column and row controls.

Edit one document or open another

Select Edit & convert in the top navigation to enter Edit & export. Choose a file, click text or a cell to edit, and use the document’s download controls when ready. For DOCX and TXT, Wording & style opens optional wording observations.

Choose Open new document beside the filename to replace it. Download the current result first if you want to keep a copy. Document options reveals the file controls and saved-work settings.

Save Word or PDF

For a DOCX document, choose Word (.docx) to download the edited Word file. To convert it, choose PDF (.pdf) → Preview PDF → Download PDF. Review the preview before downloading. Supported text headers, footers and page numbers are included.

For a PDF opened in Edit & export, use Download PDF. If the download does not start, select Save PDF to computer when the file is ready. Print opens the print workflow. For a spreadsheet, the PDF option exports the selected sheet.

Old .doc files must first be opened in Word or LibreOffice and saved as .docx; renaming the extension is not enough.

Supported files and limits

Open DOCX, PDFs with selectable text, UTF-8 TXT, XLSX, CSV and TSV, up to 2 MB per file. Images are retained in supported workflows but are not compared. Scanned PDFs need text recognition elsewhere first; existing PDF forms and comments are not supported.

Word layout may differ from Microsoft Word. Headers, footers and notes are not edited inline. Complex PDF layouts can require a text-only export, which omits images and page formatting. Spreadsheet comparison covers the selected sheet and checked columns; charts and images are not shown in the grid. Follow any file-specific notice shown when opening or exporting a document.

Resume or delete saved work

Drafts are encrypted on this device automatically; no password is needed. Older saved work is migrated when opened. If saving fails, keep the workspace open and download your result. Clearing browser data removes the draft and its key. See the privacy page for the protection limits.

Wait for Saved in this browser before closing. Use Continue → or Continue editing to reopen saved work. Drafts expire after 7 days without opening or saving them and are removed when you next open the app. Download a copy when you finish.

Open Saved work and choose Finish and delete for a comparison, or Delete saved work for one document. On an open text comparison, saved-work controls are under All tools → Files & settings; in Edit & export, they are under Document options. Each website address and installed extension stores its drafts separately. See Your files & privacy.
