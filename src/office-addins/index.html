EDIT INSIDE YOUR DOCUMENT

Word & Google Docs add-ins.

Select a passage, edit it in a panel, preview what changed and apply the edit to the original document.

These are manually installed prototypes. Installing the Chrome extension does not install either add-in. They are not published in the Microsoft or Google add-in stores.

Free to use. Your documents stay yours.

MICROSOFT WORD · PILOT 0.2.0

Review an edit in Word.

Open the task pane inside Word, load your current selection, edit and preview it, then apply it to that selection.

  • One selected passage in one ordinary paragraph, up to 4,000 UTF-16 units.
  • Requires a supported Word host with WordApi 1.4 and a separate add-in installation.
  • Save and undo through Word. Test on a copy first; native Word compatibility is not yet verified.
Open Word add-in setup

Setup includes English and Russian instructions and the XML manifest. An internet connection is required to load the panel and Microsoft’s Office.js library.

GOOGLE DOCS · PROTOTYPE 0.2.0

Edit in a Google Docs sidebar.

The existing document-bound Apps Script opens a sidebar in your Google Doc. No document download or upload to the Chrome extension is needed.

  • One continuous selection in an ordinary body paragraph, up to 4,000 UTF-16 units.
  • Install in a test copy through Extensions → Apps Script.
  • Google account, document editing access and an internet connection required.

GOOGLE DOCS SETUP

Install in one test document.

  1. Download and extract the Google Docs prototype ZIP. Open an editable test copy of a native Google Doc. Convert a DOCX copy to Google Docs format first if needed.
  2. Choose Extensions → Apps Script. Replace the default Code.gs with the file from the ZIP.
  3. Choose + → HTML, name it Sidebar, and paste the packaged Sidebar.html contents.
  4. In project settings, enable showing appsscript.json. Replace it with the packaged manifest. Save and reload your Google Doc.
  5. Select words within one ordinary paragraph. Choose Compare Two Texts → Edit selected text. Authorize access to the current document and its interface when prompted.
  6. If needed, click Load selected text. Edit, choose Preview changes, then Apply to document. Google Docs handles saving; check its save indicator.

No web-app deployment, API key or OAuth client ID is needed. Your organization’s administrator may restrict Apps Script. Installation in your Google account has not been verified by the automated tests.

Установка и работа на русском
  1. Скачайте и распакуйте ZIP. Откройте тестовую копию обычного Google Документа с правом редактирования. Файл DOCX сначала преобразуйте в формат Google Документов.
  2. Выберите Расширения → Apps Script. Замените содержимое Code.gs файлом из архива.
  3. Нажмите + → HTML, назовите файл Sidebar и вставьте содержимое Sidebar.html.
  4. В настройках проекта включите показ appsscript.json. Замените его содержимое манифестом из архива. Сохраните проект и обновите документ.
  5. Выделите несколько слов внутри одного обычного абзаца. Выберите Compare Two Texts → Edit selected text и разрешите доступ к текущему документу и его интерфейсу.
  6. При необходимости нажмите Load selected text. Внесите правку, нажмите Preview changes, проверьте результат и нажмите Apply to document. Проверьте индикатор сохранения Google Docs.

Chrome-расширение не устанавливает эту панель автоматически. Apps Script работает на стороне Google и требует интернет. Выделенный текст и полный выбранный абзац временно хранятся в открытом виде в пользовательском кэше Google; заданный срок — 15 минут. Это отдельный режим, на который не распространяется локальное шифрование черновиков расширения.

Скачать полную инструкцию с ограничениями и ручной проверкой

Start with a small, ordinary passage.

Both prototypes are for a single paragraph. Tables, lists, headers and footers, fields, comments and tracked changes or suggestions are outside the verified scope. A replacement that crosses different formatting is rejected. If the original selection or document changes, load the passage again before applying.

Previewing does not change the document. Applying a reviewed edit writes to it. Use the host editor’s Undo or version history if needed; the Google Docs prototype does not guarantee a single Undo step for the whole change.
