FILE COMPARISON GUIDE

Compare PDF files

Review text changes between two PDF versions without manually searching every page.

Open document comparison

Check that your PDFs contain text

Try selecting a sentence in your PDF viewer. A scanned page may look like text while containing only an image. Compare Two Texts needs a text layer and does not perform OCR. Each file must be no larger than 2 MB.

Compare the two versions

  1. Open the workspace. Upload the original PDF as A and the revised PDF as B, then choose Compare documents.
  2. Check the imported result. Read any file-specific notice. Complex columns, text positioning or unsupported structures can affect what the tool can display and export.
  3. Inspect each difference. Use Next difference to move between changed passages. Review their surrounding text before accepting or editing a change.
  4. Download the result you need. Use the document’s download controls for edited content. Comparison reports describe the original comparison; they are separate from your edited documents.

Example: a changed payment term

Illustrative text extracted from two versions:

A — Original: Payment is due within 30 days.

B — Revised: Payment is due within 14 days.

The difference is in the wording. A changed logo, signature image or page background is outside this text comparison.

Know the PDF limits

This is not a pixel-by-pixel visual comparison. Images are not compared. Existing PDF forms and comments are not supported. Complex layouts may require a text-only export that omits images and page formatting. Review the export notice and the saved file.

To edit one PDF, open Edit & convert, load the file and use Download PDF when ready. Document processing stays in your browser; see Your files & privacy.

Common questions

Can I compare scanned PDFs?

Run OCR in another application first, then use PDFs containing selectable text. Check that the recognized text is accurate.

Should I compare DOCX or PDF?

If both original Word files are available, compare the DOCX versions to work with their supported paragraphs and tables before PDF conversion.

Does comparison detect formatting-only changes?

It focuses on text differences. Review visual layout, graphics and signatures separately.
