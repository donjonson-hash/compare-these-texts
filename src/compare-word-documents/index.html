FILE COMPARISON GUIDE

Compare two Word documents

Find changed wording and table entries in two DOCX versions, then edit the passages you choose. Microsoft Word is not required.

Open document comparisonAdd to Chrome — free

How to compare two Word documents

  1. Prepare your files. Use DOCX files up to 2 MB each. Save older .doc files as .docx in Word or LibreOffice first.
  2. Choose the versions. Open the comparison workspace. Upload the original under A and the revised document under B, then select Compare documents.
  3. Review changes in context. Move through highlighted differences with Next difference. Select a passage to edit it. During a guided review, use Use A or Keep B to decide what belongs in the result.
  4. Save the edited version. Use the download control for A or B. Open the downloaded DOCX and check the final layout before sharing it.

Example: a revised delivery date

This is an illustrative change, not an uploaded document.

A — Original: Delivery within 5 business days.

B — Revised: Delivery within 10 business days.

Review that sentence alongside its surrounding terms. Keep the revised date, restore the original or type an agreed value. The same workflow helps check quantities and wording inside supported tables.

Compare documents in Microsoft Word

The desktop version of Word has a built-in comparison. It is not available in Word for the web.

  1. Open Compare. In Word, go to the Review tab and choose Compare, then Compare again.
  2. Choose the versions. Select the original file under Original document and the newer file under Revised document, then select OK.
  3. Review the result. Word opens a new document that shows the differences as tracked changes. Accept or reject each change, then save.

Compare two Google Docs

In Google Docs, open one document and choose Tools, then Compare documents. Select the second document and confirm. Google Docs creates a new document that shows the differences as suggestions.

To see both versions side by side instead, download each one with File, then Download, then Microsoft Word (.docx), and open both files in the comparison workspace.

Which method should you use?

  • Microsoft Word: best when you want tracked changes in one document and have the desktop app.
  • Google Docs: best when both versions are already in Google Docs.
  • Compare Two Texts: best when you want both versions side by side, do not have Word installed, or prefer not to upload the files to a web service. It does not create tracked changes.

What this comparison covers

The tool compares supported text and table content. It is not a complete comparison of Word formatting or a replacement for Microsoft Word’s Track Changes. Images are not compared, and headers, footers and notes are not edited inline. Some complex structures may be restricted; read any notice shown for your file.

Document processing happens in your browser. See how files and saved drafts are handled.

Common questions

Can I upload a .doc file?

Save it as DOCX first. Changing the filename from .doc to .docx does not convert the document.

Will the downloaded Word file look identical?

Layout may differ from Word, particularly for complex documents. Review the exported file before sending it.

Can I compare Word docs without Microsoft Word?

Yes. The comparison runs in your browser, so Word does not need to be installed. File limits and supported structures still apply. Open the downloaded DOCX in your usual editor to check the final layout.

How do I compare a PDF version instead?

Use the PDF comparison guide. The PDF needs selectable text; scanned pages need text recognition elsewhere first.
