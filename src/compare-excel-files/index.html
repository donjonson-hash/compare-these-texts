FILE COMPARISON GUIDE

Compare two Excel files for differences

Compare two Excel sheets, one selected from each file, by matching rows on an identifier. Then check changed values and missing records.

Open document comparisonAdd to Chrome — free

Prepare a comparable sheet

Use XLSX files up to 2 MB each, with no more than 5,000 data rows in the selected sheet. The first filled row supplies the column headers. Give every column a nonempty, unique name and remove merged cells from the comparison copy.

Formulas are not recalculated or compared. If the selected sheet contains formulas, save a separate values-only copy first. Keep long product codes and identifiers as text so their digits are preserved.

How to compare two Excel sheets

  1. Upload A and B. Choose the original workbook and its revised version, then select Compare documents.
  2. Choose the sheets. If a workbook has several populated sheets, select the sheet you want to compare. This is a selected-sheet comparison, not a whole-workbook audit.
  3. Check the identifier and fields. Use a shared ID, SKU or other unique key to match records. Check the column mapping and select the fields whose values matter.
  4. Review the results. Inspect changed values and records found on only one side. Confirm the settings before editing or downloading a report.

Example: reordered inventory rows

Illustrative record in two sheets:

A — SKU LAMP-01: Quantity 12, unit price 35.00.

B — SKU LAMP-01: Quantity 10, unit price 35.00.

Matching by SKU lets you inspect the quantity change even if the item moved to another row. Comparing row positions alone would obscure that relationship.

Understand the scope

Hidden rows and columns in the selected sheet are included; empty rows are skipped. Formatting, charts, images and comments are not compared. Numeric values and supported dates may be normalized, so a visual formatting difference is not necessarily a value change.

Common questions

Can the column names differ?

Check the mapping between the two files and match the corresponding fields. An identifier must refer to the same item on both sides.

Why is my sheet rejected?

Check for formulas, merged cells, missing or repeated headers and file limits. Follow the specific notice shown by the tool.

Can I compare a CSV export?

Yes. The CSV comparison guide explains delimiters, encoding and matching records.
