MICROSOFT WORD · PILOT 0.1.0

Make your edit inside Word.

Select a passage in your document, edit it in a side panel, review the replacement and apply it to the original passage. Save and Undo stay in Word.

This is a new test add-in, not a Microsoft Marketplace release. Automated checks use an Office API model; activation, formatting and Undo still need testing in your real Word client. Start with a test copy.

Download Word add-in manifest

Requires an editable document, internet access and WordApi 1.4. Your organization may restrict custom add-ins. Installing the Chrome extension does not install this Word add-in.

Install in Word for the web

  1. Download the manifest above.
  2. Open a test document in Word for the web. Choose Home → Add-ins → More Settings.
  3. Choose Upload My Add-in, select the downloaded XML manifest and confirm.
  4. The Compare Two Texts task pane opens. Select ordinary text in the document and choose Load selected text.

Microsoft’s web installation instructions

Install in Word on Mac

  1. Download the same manifest.
  2. In Finder, press ⌘⇧G. Open ~/Library/Containers/com.microsoft.Word/Data/Documents/wef. Create the wef folder if it does not exist.
  3. Copy the manifest XML into that folder. Restart Word.
  4. Open a test document, then choose Home → Add-ins → Compare Two Texts — Word pilot.

Microsoft’s Mac installation instructions

For Windows desktop or organization-wide deployment, use your administrator’s supported add-in deployment process. The web route above is the simplest initial pilot; this page does not install software on your computer.

Edit and save

  1. Select one continuous passage, without the paragraph-end mark. Choose Load selected text.
  2. Edit the text in the panel and choose Preview changes. Removed text is crossed out; additions are underlined.
  3. Keep the original passage selected. Choose Apply to Word. The add-in rechecks that the text, formatting and selection have not changed.
  4. Check the result in the document and save normally in Word. Use Word’s Undo to revert. A single combined Undo step is not guaranteed.

The add-in never saves the file itself. Closing or reloading the panel discards its draft. A loaded selection expires after 15 minutes.

Supported pilot scope

One consistently formatted selection of up to 4,000 UTF-16 units inside one ordinary body paragraph of up to 12,000 units. Most letters use one unit; many emoji use two. Unselected content is not replaced. Word handles the replacement’s formatting.

Tables, lists, headers and footers, links, fields, bookmarks, comments, content controls, embedded objects, paragraph breaks and Track Changes are unsupported. The selected paragraph must contain ordinary text only. A selection crossing different character formatting is rejected; edit each formatted passage separately.

Avoid simultaneous manual or collaborative editing while applying. Office APIs do not offer an atomic compare-and-write transaction. If Word reports an uncertain write, inspect the document before retrying; the panel keeps your draft available to copy.

Where your document goes

The panel is downloaded from comparetwotexts.pro; Office.js is downloaded from Microsoft’s official CDN. This requires internet access. Our add-in code reads the selected passage and its paragraph into panel memory, and sends the approved replacement back to Word through Office.js. It does not upload document text to Compare Two Texts, call an AI service, run analytics or save a draft in browser storage.

Microsoft Word’s own cloud saving, collaboration, library and service behavior remain governed by your Microsoft account and organization settings. This hosted add-in is separate from the offline Chrome comparison workspace.

Краткая инструкция на русском

Это пилот отдельного дополнения для Microsoft Word. Установка расширения Chrome не добавляет его в Word автоматически.

  1. Скачайте XML по кнопке выше. В Word в браузере: Главная → Надстройки → Дополнительные настройки → Загрузить мою надстройку. Названия могут отличаться в вашей версии.
  2. На Mac скопируйте XML в ~/Library/Containers/com.microsoft.Word/Data/Documents/wef, перезапустите Word и откройте дополнение через меню надстроек.
  3. Выделите один фрагмент обычного абзаца без знака конца абзаца. Нажмите Load selected text, отредактируйте текст, затем Preview changes и Apply to Word.
  4. Проверьте результат и сохраните документ в Word. Отмена — средствами Word.

До 4 000 единиц UTF-16, единое форматирование выделенного фрагмента. Таблицы, списки, поля, ссылки, комментарии и режим записи исправлений пока не поддерживаются. Не меняйте исходное выделение до применения. Текст не отправляется нашим кодом на сервер или в ИИ; панель и Office.js загружаются по сети. Проверка в настоящем Word на вашем устройстве ещё необходима — начните с тестовой копии.
