WORD ADD-IN · PILOT 0.2.0

Edit selected text

Select one consistently formatted passage in an ordinary Word paragraph. Load it here, edit, preview, then apply.

Connecting to Word. This panel works when installed as a Word add-in.

Original selected text

One paragraph; up to 4,000 UTF-16 units (most letters use one; many emoji use two). No line breaks.

Review the replacement

Removed text is crossed out; added text is underlined. This previews one replacement from the first to the last changed character.

How saving and privacy work

Apply writes to your selected passage. Save and Undo work through Word. Keep the original passage selected until you apply. Avoid simultaneous edits by collaborators.

The panel loads from Compare Two Texts; Microsoft supplies Office.js. Our add-in code does not send document text to a server or AI service, and does not store drafts. Word’s own cloud saving and data handling still apply.

Pilot: ordinary body text only. Tables, lists, links, fields, bookmarks, comments, content controls and Track Changes are unsupported. Mixed formatting within the selection is rejected. A change to the original text, formatting or selection requires loading it again.

Native Word testing on your device is still required. Use a test copy for your first check.
